## 3. CONTRAT DE LIVRAISON — Règles pour les agents MCP

Tout contenu livré par un agent doit respecter ces règles. Le rédac-chef (cette fenêtre CMS) vérifie et corrige après livraison.

### Taxonomie

```
univpilar : esprit | corps | liens | monde | avenir     (OBLIGATOIRE)
rubrique  : articles | videos | guides                   (OBLIGATOIRE)
category  : comprendre | reflexions | temoignages | portraits   (articles)
            reportages | interviews | documentaires             (videos)
            programmes | ateliers | masterclass | kits-gratuits (guides)
soustopic : doit appartenir à l'univpilar choisi         (OBLIGATOIRE)
tags      : chaînes libres, pas de références Sanity
```

### Format des blocs riches

#### Callouts
```json
{
  "_type": "callout",
  "type": "tip | warning | info | important",
  "title": "string",
  "content": [{ "_type": "block", "children": [{ "_type": "span", "text": "..." }] }]
}
```
**INTERDIT** : `titre` au lieu de `title`, `contenu` au lieu de `content`, `content` en string.

#### Citations (styledQuote)
```json
{
  "_type": "styledQuote",
  "quote": "Le texte de la citation",
  "author": "Nom de l'auteur",
  "role": "Fonction",
  "source": "Titre du livre ou de l'étude",
  "sourceUrl": "https://lien-vers-la-source.com",
  "style": "classic | elegant | minimal | large"
}
```
**OBLIGATOIRE** : `sourceUrl` si un lien existe. Pas de markdown dans `source`.

#### Sources et liens dans le contenu
- Les URLs doivent être intégrées comme annotations de lien sur du texte
- **INTERDIT** : `Source : https://url-brute-dans-le-texte`
- **CORRECT** : le texte "Source" avec une annotation `link` pointant vers l'URL

### Contenu éditorial

#### Les 12 mots interdits
Ne jamais utiliser : exclusif, décrypter, "dans un monde où", "experts disent", booster, contenu, audience, game changer, storytelling, authentique (show don't tell), incroyable/dingue/fou

#### Structure obligatoire
- Première phrase : une scène (personne, lieu, objet), jamais une définition ou une stat
- Paragraphes : 3-5 lignes max
- Sous-titre (H2) : tous les 400-600 mots
- Sources : (Auteur · Année · Médium) à la première mention
- Fermeture : question ouverte, jamais un résumé

#### Typographie française
- Guillemets : « » avec espaces insécables
- Apostrophe courbe : ' (jamais droite)
- Tiret cadratin : — avec espaces des deux côtés
- Nombres : en lettres de 0 à 16, en chiffres à partir de 17
- Pourcentages : chiffre + symbole avec espace insécable (28 %)

#### Images
- Obligatoire pour chaque article et recommandation
- Style : photo éditoriale magazine, cinématique, pas de stock générique
- ZERO texte sur les images générées
- Format : min 1200px, WebP ou JPEG < 200 Ko

### Maillage interne
- 3-5 liens internes par article
- Ne jamais inventer de slugs — vérifier avec `verify-internal-links.js`
- Bloc "À lire aussi" en fin d'article (3 articles liés)

```
1. Alex décide    → "Je veux 5 articles sur la respiration"
2. Rédac-chef     → Rédige les briefs (titre, angle, univpilar, soustopic, format)
                  → Les envoie aux agents MCP via prompt structuré
3. Agents MCP     → Produisent les articles via create_article
                  → Génèrent les images via generate_image
4. Rédac-chef     → Audit qualité (callouts, sources, typo, taxonomie)
                  → Corrige directement dans Sanity si nécessaire
                  → Lance le maillage interne (related articles + contextual links)
5. Alex valide    → Relit, ajuste, publie
6. Rédac-chef     → Met à jour la curation homepage si pertinent
                  → Met à jour l'état du catalogue
```

## 7. BRIEF TYPE — Template pour commander un article

```markdown
## Brief #XX — [Titre provisoire]

**Univpilar** : corps
**Soustopic** : respiration
**Rubrique** : articles
**Catégorie** : comprendre
**Format** : article long (1800-4000 mots)
**Famille de titre** : titre-question

**Angle** : Explorer la cohérence cardiaque non comme une mode wellness
mais comme un protocole physiologique documenté. Partir d'une scène
concrète (un cadre en burn-out qui découvre l'exercice chez un cardiologue).

**Sources attendues** :
- Études peer-reviewed sur la variabilité cardiaque
- Au moins un professionnel de santé nommé
- Un témoignage incarné

**Blocs riches attendus** :
- 2-3 callouts (tip, info)
- 1 citation sourcée avec sourceUrl
- 1 bloc points clés en fin d'article

**Maillage** : lier vers les articles existants sur le stress,
la méditation, le sommeil.

**Image** : scène intimiste, une personne les yeux fermés,
lumière naturelle douce, grain photographique.
```
